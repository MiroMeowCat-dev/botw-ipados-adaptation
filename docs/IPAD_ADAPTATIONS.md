# iPad 专项适配原理

## 模块与边界

| 模块 | 实际职责 |
| --- | --- |
| BotWDisplay | 启动读取画面/帧率/性能开关，配置宿主环境，屏幕输出和本地摘要 |
| BotWInventoryProbe | 背包图形识别、自动比例状态机、CoreMotion 六轴桥接、统一设置面板 |
| BotWTouchLayout | 虚拟手柄显示与布局编辑，触控映射、保存取消和输入释放 |

`botw_ipad_v10.m` 合入背包与体感；`botw_ingame_settings.m` 与 `botw_release_settings.py` 共享设置语义。宿主 API 的 UUID、函数地址、短指令签名均固定。加载时校验 UUID / 签名，地址叠加 ASLR slide；不匹配就不调用。它们不是适用于所有游戏或宿主版本的通用地址。运行时不写入可执行内存。

## 分辨率、画幅与 MetalFX

11 英寸 M5 面板为 2420×1668，比例约 1.451，比 16:9 更窄。

| 档位 | 场景与呈现 |
| --- | --- |
| legacy | handheld 兼容，约 540p 场景 / 720p 画布 |
| 1080 | docked 1920×1080 场景，1080p 游戏区域 |
| panel | 相同 1080p 场景，普通放大到屏幕输出 |
| panel-mfx | 相同 1080p 场景，宿主 MetalFX Spatial 放大到屏幕输出 |

16:9 模式下，全屏 drawable 2420×1668 中游戏区域约为 2420×1361，其余为黑边；1080p 档 drawable 可约为 1919/1920×1323，游戏区域约 1920×1080。HUD 的 drawable 尺寸、缩放输入、游戏区域三个数不能混为内部 3D 分辨率。

`TOTK_OPERATION_MODE=docked` 选择场景档位；`TOTK_IOS_DRAWABLE_H` 配置输出尺寸。`TOTK_MFX_UPSCALE` / `TOTK_MFX_OUTPUT` 启用已有 Spatial 路径，旧 temporal 开关 `TOTK_MFX=0`。空间超分对当前图像重建和锐化，缺少此前帧/运动矢量，不能等同 Temporal，也不是插帧。目前未实现更高于 1080p 的内部渲染配置。

全屏采用宿主 `TOTK_ASPECT=2420x1668` 与原有 aspect writer 改变相机比例，而非把人物横向压扁。iPad 相比 16:9 会减少两侧取景。UI 不是统一透视相机，背包的裁切/预览等因此会错位。

画质、画幅、限帧等启动项需保存后从多任务彻底退出再开。系统设置返回上一级以提交偏好；必要时退出系统设置重新进入确认。曾经看到“所有选项都全屏”的现象，经直接读值与重新保存后，16:9 对照恢复正常。

## 背包自动兼容与退出节奏

检测固定宿主渲染中背包特征，把正/负观察写入 64 槽原子环形缓冲，结合宿主帧编号判断。它不是按截图 OCR 或单纯监听“＋”键，因此可覆盖不同打开/退出路径。

- 连续两帧正观察后进入背包状态，使用 16:9。
- 退出需至少连续三帧负观察，且负观察持续至少 50 ms。
- 未观察帧、停帧、背景切换不当成菜单退出证据；一个编码区间内正观察优先。
- 显示检查约 60 Hz；这些帧是已观察的宿主编码区间，不代表 GPU 已完成帧。

v6 用约 600 ms 保护期 + 100 ms 轮询，退出存在明显延迟；v7 改为上述证据状态机，用户确认恢复更快。仍有约束性的切换/防抖时间，并未彻底重做背包为原生 iPad 比例。固定全屏可能重现错位，推荐自动兼容。其他菜单仍需覆盖测试。

## 体感

CoreMotion 提供 `deviceMotion`，将 gravity + userAcceleration 与 rotationRate 根据横屏方向转换坐标，送入宿主已有六轴融合，再由游戏的体感读取链消费。内部函数名包含 `mouse` 是原宿主历史命名，不表示模拟鼠标或右摇杆。

桥接运行在串行队列，约 5 ms tick；这是保持/积分有效样本的桥接节奏，不表示传感器有 200 Hz 新样本。拒绝非有限、未来或超 50 ms 的过旧数据，后台、关闭开关、旋转方向变化时释放 feed。校准完成由该队列回报，避免 UI 假报完成。需同时开启游戏自身“体感瞄准”。用户已验证望远镜/瞄准方向正常。

## 虚拟手柄与设置

复用宿主触控控件，提供拖动、单控件大小/透明度、固定/浮动摇杆和布局保存，保留 `BOTW_TOUCH_LAYOUT_V1` 偏好键。v2 的 ARC 字符串所有权问题导致启动崩溃，v3 修复 strong NSString 标签与初始化。取消恢复编辑前布局；隐藏手柄、进入设置时释放按键，避免卡键。

v10 将体感、背包、布局集中到系统风格设置；手柄与设置入口分别控制。入口隐藏后从“设置 → App → 塞尔达 → 界面 → 显示游戏内设置入口”恢复。两个设置界面由同一 schema 驱动；布局编辑/校准动作仅在游戏内执行。设置和编辑器不会自动暂停世界，调整前先按游戏「＋」暂停。

## 限帧与诊断

v9 修正显式上限与宿主旧 interval 重复作用的情况：明确 30/60 上限时采用 `DM_PRESENT_INTERVAL=display`，避免目标 60 又被 interval=2 降为 30。跟随游戏模式保留，游戏物理 timestep 不改。

v10 首次日常启动关闭此前测试开关，HUD insights 提示不作为常驻 UI；诊断按需开启，只写本地。减少提示显示不是解决全部性能问题。CPU 编码占比高、重复 render pass、首次着色器编译等底层优化尚未完成；没有迁移整个渲染器到 MTL4CommandBuffer/MTL4Compiler。
